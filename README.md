# Hostly — website redesign mock

Single self-contained `index.html` (no build step — open it directly in a browser).
A boutique property / short-term-rental management site built from the Instagram brand
identity (`@hostly.ca`): forest-green + cream, botanical leaf-and-house mark.

## Design
- **Palette:** warm paper cream + deep forest green, sage accents — pulled straight from the logo.
- **Type:** Cormorant Garamond (display serif) + Jost (sans).
- **Motion:** Lenis smooth-scroll + GSAP ScrollTrigger — cinematic hero, pinned guest-ready
  reveal, scroll-velocity marquee, pinned portfolio cards, ambient orbs. Full reduced-motion
  and no-JS fallbacks.
- Sections: Hero · Guest-ready reveal · Full-service hosting (6 services) · Marquee ·
  The Hostly Standard · Homes portfolio · Results stats · Free-estimate contact · Footer.
- Imagery: verified Unsplash hotlinks (interiors + dusk exterior).
